# 💕 默契大考验 · 异地情侣版

> 一个单文件、零依赖的网页小游戏：异地情侣各答一遍同样的 10 道「二选一」题，立刻算出你们的默契值。

- **无需服务器**：整个游戏就是 `index.html` 一个文件，双击即可玩
- **无需注册登录**：所有数据都编码在「密令」字符串里，双方各答一次就能出结果
- **题库 80 对**：每局从中随机抽 10 题，题目顺序由随机种子决定，保证两人拿到完全相同的题目

## 🎮 玩法

「一个人先答 → 生成密令 → 另一个人答 → 出默契值」的三步流程：

1. **① 我先答题，生成密令** — 填好双方昵称，答完 10 题后页面给出一串 6 位密令（例如 `0ABCDE`），复制发给对方。
2. **② 输入密令，开始作答** — 对方打开同一个页面，填昵称、粘贴密令，回答**完全相同的 10 道题**（看不到你先前的答案）。
3. **③ 输入回执，查看结果** — 对方答完后会得到一串 7 位**回执密令**，把它发回给你；你选「③ 输入回执」粘贴，双方都能看到逐题对比和默契值。

答题过程中会实时显示默契值：每题一致 +10 分，满分 100 分。

小细节：答错了可以点「← 上一题」退回去重选（后答方退回去时，已经加过的分数会一并撤销）；答题中途误触刷新、误关页面也不会丢进度 —— 回到首页点「继续上次答题」就能接着答。

### 评分档位

| 默契值 | 称号 |
| --- | --- |
| 90 - 100 | 💞 天生一对！异地也挡不住你们共用一个大脑 |
| 70 - 89 | 💖 心有灵犀！大多数选择都不谋而合 |
| 50 - 69 | 💗 磨合中的小情侣 |
| 30 - 49 | 🌱 还需多了解彼此（今晚视频就聊这些题吧） |
| 0 - 29 | 🤪 互补型选手（几乎完全不同，传说中的互补） |

结果页会逐题列出「题面 ｜ 你先答的 ｜ TA 答的」，选择一致的题目高亮显示。

## 🛠 技术说明

- 纯原生 HTML + CSS + JavaScript，**零依赖、无构建步骤、无后端**
- 随机种子和双方答案全部编码进密令，因此不需要服务器、数据库或账号系统

### 密令编码格式

每道题的答案被压成 1 个 bit（0 = 选第一个选项，1 = 选第二个），再和题库版本、随机种子拼成一个整数，转成大写的 base36 字符串：

| 类型 | 长度 | 组成 |
| --- | --- | --- |
| 密令（先答方 → 后答方） | 6 位 base36 | 题库版本 4 bit + 随机种子 12 bit + 先答方答案 10 bit |
| 回执（后答方 → 先答方） | 7 位 base36 | 题库版本 4 bit + 随机种子 12 bit + 先答方答案 10 bit + 后答方答案 10 bit |

题目顺序由随机种子经 `mulberry32` 伪随机洗牌决定，所以拿到同一串密令的两个人，题目内容与顺序必然完全一致。

## 🚀 使用与部署

**本地直接玩**：用浏览器打开 `index.html`（双击即可）。

也可以起一个本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

**发布到 GitHub Pages**（这样对方点个链接就能玩）：

1. 打开仓库 **Settings → Pages**
2. Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，保存
3. 稍等片刻，访问 `https://joewang911.github.io/couple-game/`

> ⚠️ GitHub Pages 目前**尚未启用**，上面这个地址需要先按步骤开启才能访问。

## ✏️ 如何增加题目

1. 打开 `index.html`，在 `QUESTIONS` 数组末尾按 `["选项A","选项B"]` 的格式追加题目（每题必须正好两个选项）
2. **把 `CODE_VERSION` 加 1**（就在 `QUESTIONS` 数组下方，约第 203 行）

   这一步不能省：否则用旧题库生成的密令会和新题库错位，算出乱七八糟的结果。
3. 提交并推送

因为密令里带了版本号，题库更新后旧密令会被明确拦下并提示「这个密令来自旧版本题库，游戏已更新」，而不是给出错误答案。

## 📱 浏览器支持

移动端与桌面端的现代浏览器均可运行。已做移动端适配：禁用双击缩放、选项按钮按压反馈、`navigator.vibrate` 震动反馈；复制密令优先使用 `navigator.clipboard`，不支持时自动降级为弹窗手动复制。
